# 統一發票線上對獎

Windows 桌面程式雛形，啟動後連線讀取財政部官方開獎資料。可在最新公布期別及之前兩期之間切換，輸入 3 碼或完整 8 碼號碼，逐張記錄並累加本次中獎金額。

## 執行

安裝 Python 3.10 以上版本後，在此資料夾執行：

```powershell
py app.py
```

## 製作 EXE

```powershell
py -m pip install pyinstaller
build_exe.bat
```

完成後執行 `dist\InvoicePrizeChecker.exe`。程式本身只用 Python 標準函式庫；PyInstaller 只在打包時需要。EXE 執行時需連網，且不提供離線對獎。

程式圖示素材位於 `assets/`；打包時會同時設為 Windows EXE 圖示及視窗圖示。

## 對獎規則

3 碼輸入平常判斷六獎（含增開六獎）。若末三碼符合頭獎、特獎或特別獎號碼，程式會要求補輸入完整 8 碼，再依最高獎項規則判定；也可直接輸入完整 8 碼。單張僅計最高獎項。特別獎及特獎需全號碼相同，頭獎至六獎依序比對末 8 至末 3 碼。

號碼來源為財政部稅務入口網。此工具只比對獎號，不會判斷領獎期限、發票資格或稅費；領獎請以財政部公告為準。
